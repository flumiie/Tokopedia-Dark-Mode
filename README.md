## Installation

### Via Userstyles.world
You can easily install this style using the Stylus browser extension:
[Install from Userstyles.world](https://userstyles.world/style/18214/default-slug)

### Manual Installation
1.  Ensure you have the [Stylus](https://add0n.com/stylus.html) browser extension installed.
2.  Copy the code from `index.css`.
3.  Open Stylus, click "Write new style".
4.  Paste the code and save.
